# dotindot.in

The public website. A static site generated by one Node script — no framework, no database, nothing to patch. Light theme only.

- **Dot**, the mascot, lives in the bottom corner on every page. It starts as the full stop of each page headline and rolls into its corner as you scroll, follows the cursor, reacts to buttons (hearts on "Free audit", covers its eyes on "Employee login"), gets dizzy if you scroll too fast, naps when idle, says hello once per visit, offers a nudge on exit, and opens a quick-help menu (audit, WhatsApp, email, jokes) when tapped.
- **Motion moments**: a pinned "Watch the dots work" theatre with six animated service films; Dot falls on the word "average" and squashes it flat; pages open out of a growing orange dot (cross-document view transitions in Chrome, Edge and Safari); and at the bottom of every page Dot rolls into the footer logo and becomes its full stop. Visitors can grab Dot and throw it — it bounces off the screen edges and rolls home.
- **Lead tools**: the Growth Score quiz (score out of 100 + top fixes + email capture), a real website speed test using Google PageSpeed Insights (scores, Core Web Vitals, "send me the fix list"), Dot's call-me-back and email mini-forms, a one-time mid-page and exit nudge, and confetti on every successful lead.
- **Smooth scrolling** with Lenis; scroll-driven scenes (the dot-universe that becomes a world map, a sideways process reel, headings that lean into fast scrolls, a speed-reactive marquee). Everything respects *reduced motion* and still works with JavaScript off.
- **Global by default**: local time and place from the visitor's time zone, budgets shown in their currency (USD, GBP, EUR, AED, SGD, AUD, CAD, INR), live world clocks.
- **Leads go straight into the CRM** (Sales → Pipeline) — the website and the CRM are one app, so forms post to `/api/intake/website` on the same address, no key or CORS needed. Each lead is tagged with source (website / ads / LinkedIn / referral from UTM), interest, budget and currency, time zone, landing page and referrer. If the CRM is unreachable the visitor gets a one-tap WhatsApp fallback.
- **Speed + SEO + AI search**: Lighthouse mobile 100 / 100 / 100 / 100 on every indexable page, self-hosted fonts, a home page lighter than one phone photo, and the full SEO set below.

## Edit → publish

The website is part of the one dotindot app: it is served at `/`, the employee & client app at `/app`, the API at `/api` (see `deploy/README.md` in the repo root).

1. Edit copy in `src/content.mjs` and your details in `site.config.json`:
   - `email`, `phone`, `phoneDisplay`, `whatsapp` (digits only, with country code) — **the phone/WhatsApp numbers in the file are placeholders**.
   - `social` links (empty ones are hidden).
   - `proof`, `testimonials`, `caseStudies` — real numbers only; empty values stay hidden.
   - `receipts.lighthouse` — the score shown on the home page. Re-run Lighthouse after big changes; clear it to hide that block.
   - `employeeLogin`, `clientLogin`, `leadIntakeUrl` — already point at the app (`/app/login`, `/app/portal/login`, `/api/intake/website`).
2. Try it locally: `node build.mjs` (Node 18+) → `dist/`. If `esbuild` is installed the script is minified.
3. Publish: push to git, then on the server `bash deploy/deploy.sh` (builds the website and the app, swaps them in, restarts).

Preview build for a static preview host: `PREVIEW=1 node build.mjs` (relative links, forms show a success message without sending, login links open an app preview copied to `app/`).

## Search engines (once)

- Search Console / Bing: paste the HTML-tag verification values into `verify.google` / `verify.bing`, rebuild, upload, then submit `https://dotindot.in/sitemap.xml` in both.
- Optional: put a free Google Cloud API key (PageSpeed Insights API enabled) in `pageSpeedApiKey` so the speed test gets a bigger daily quota.
- Share images: `node og.mjs` (needs Playwright) re-renders `assets/og/*.jpg` after you change titles; then rebuild.
- Every page ships with title, description, canonical, hreflang, Open Graph/Twitter cards with its own image, and JSON-LD (Organization, WebSite, WebPage with speakable, BreadcrumbList, Service, FAQPage, ItemList, Blog/BlogPosting, HowTo, WebApplication for the free tools). Also `sitemap.xml`, `robots.txt` (AI crawlers welcome), `llms.txt`, `llms-full.txt`, `humans.txt` and `.well-known/security.txt`.

## Files

- `build.mjs` — page templates, schema, sitemap, robots, llms.txt (and an `.htaccess` in case the site is ever hosted on Apache)
- `src/content.mjs` — all copy (services, process, FAQs, jokes, articles, roles, markets, quiz)
- `src/scenes.mjs` — the six animated service films (SVG)
- `og.mjs` — renders the per-page share images (dev only)
- `src/styles.css` — design tokens and styles (inlined into every page)
- `src/site.js` — Dot (moods, throwing, logo landing), smooth scroll, scenes, quiz, speed test, clocks, currency, forms
- `assets/fonts` — Anybody + Instrument Sans, subset to Latin (both SIL Open Font License)
- `assets/vendor` — Lenis (MIT) and the dotted world-map points
