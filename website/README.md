# dotindot.in

The public website. A static site generated by one Node script — no framework, no database, nothing to patch. Light theme only.

- **Dot**, the mascot, lives in the bottom corner on every page. It starts as the full stop of each page headline and rolls into its corner as you scroll, follows the cursor, reacts to buttons (hearts on "Free audit", covers its eyes on "Employee login"), gets dizzy if you scroll too fast, naps when idle, says hello once per visit, offers a nudge on exit, and opens a quick-help menu (audit, WhatsApp, email, jokes) when tapped.
- **Smooth scrolling** with Lenis; scroll-driven scenes (the dot-universe that becomes a world map, a sideways process reel, headings that lean into fast scrolls, a speed-reactive marquee). Everything respects *reduced motion* and still works with JavaScript off.
- **Global by default**: local time and place from the visitor's time zone, budgets shown in their currency (USD, GBP, EUR, AED, SGD, AUD, CAD, INR), live world clocks.
- **Leads go straight into the CRM** at internal.dotindot.in (Lead Flow → our pipeline), tagged with source (website / ads / LinkedIn / referral from UTM), interest, budget and currency, time zone, landing page and referrer. If the CRM is unreachable the visitor gets a one-tap WhatsApp fallback.
- **Speed + SEO + AI search**: Lighthouse mobile 100 / 100 / 100 / 100 on every indexable page, self-hosted fonts, ~200 KB home page, Organization / Service / FAQ / Article / Breadcrumb schema, sitemap, robots (AI crawlers welcome), `llms.txt` and `llms-full.txt`.

## Edit → build → upload

1. Edit copy in `src/content.mjs` and your details in `site.config.json`:
   - `email`, `phone`, `phoneDisplay`, `whatsapp` (digits only, with country code) — **the phone/WhatsApp numbers in the file are placeholders**.
   - `social` links (empty ones are hidden).
   - `leadIntakeUrl` — see below.
   - `proof`, `testimonials`, `caseStudies` — real numbers only; empty values stay hidden.
   - `receipts.lighthouse` — the score shown on the home page. Re-run Lighthouse after big changes; clear it to hide that block.
2. Build: `node build.mjs` (Node 18+). Output goes to `dist/`. If `esbuild` is installed globally the script is minified; otherwise it ships as-is.
3. Upload **the contents of** `dist/` (including the hidden `.htaccess`) to `public_html` in hPanel → File Manager, replacing the old site.

Preview build for a sub-folder or static preview host: `PREVIEW=1 node build.mjs` (relative links, forms show a success message without sending).

## Connect the forms to the CRM (once)

1. In internal.dotindot.in open **Lead Flow → Our capture link** and copy the key at the end of the link.
2. Put it in `site.config.json` → `leadIntakeUrl`: `https://internal.dotindot.in/api/intake/leads/<your key>` and rebuild.
3. On the VPS, make sure the backend `.env` allows the website: `CORS_ORIGINS=https://dotindot.in,https://www.dotindot.in,https://internal.dotindot.in`, then `pm2 restart dotindot-backend`.

## Files

- `build.mjs` — page templates, schema, sitemap, robots, llms.txt, .htaccess
- `src/content.mjs` — all copy (services, process, FAQs, jokes, articles, roles)
- `src/styles.css` — design tokens and styles (inlined into every page)
- `src/site.js` — Dot, smooth scroll, scenes, clocks, currency, forms
- `assets/fonts` — Anybody + Instrument Sans, subset to Latin (both SIL Open Font License)
- `assets/vendor` — Lenis (MIT) and the dotted world-map points
