# dotindot.in

The public website. A static site generated by one Node script — no framework, no database, nothing to patch. Light theme only.

- **Dot**, the mascot, lives in the bottom corner on every page. It starts as the full stop of each page headline and rolls into its corner as you scroll, follows the cursor, reacts to buttons (hearts on "Free audit", covers its eyes on "Employee login"), gets dizzy if you scroll too fast, naps when idle, says hello once per visit, offers a nudge on exit, and opens a quick-help menu (audit, WhatsApp, email, jokes) when tapped.
- **Motion moments**: a pinned "Watch the dots work" theatre with six animated service films; Dot falls on the word "average" and squashes it flat; pages open out of a growing orange dot (cross-document view transitions in Chrome, Edge and Safari); and at the bottom of every page Dot rolls into the footer logo and becomes its full stop. Visitors can grab Dot and throw it — it bounces off the screen edges and rolls home.
- **Lead tools**: the Growth Score quiz (score out of 100 + top fixes + email capture), a real website speed test using Google PageSpeed Insights (scores, Core Web Vitals, "send me the fix list"), Dot's call-me-back and email mini-forms, a one-time mid-page and exit nudge, and confetti on every successful lead.
- **Smooth scrolling** with Lenis; scroll-driven scenes (the dot-universe that becomes a world map, a sideways process reel, headings that lean into fast scrolls, a speed-reactive marquee). Everything respects *reduced motion* and still works with JavaScript off.
- **Global by default**: local time and place from the visitor's time zone, budgets shown in their currency (USD, GBP, EUR, AED, SGD, AUD, CAD, INR), live world clocks.
- **Leads go straight into the CRM** at internal.dotindot.in (Lead Flow → our pipeline), tagged with source (website / ads / LinkedIn / referral from UTM), interest, budget and currency, time zone, landing page and referrer. If the CRM is unreachable the visitor gets a one-tap WhatsApp fallback.
- **Speed + SEO + AI search**: Lighthouse mobile 100 / 100 / 100 / 100 on every indexable page, self-hosted fonts, a home page lighter than one phone photo, and the full SEO set below.

## Edit → build → upload

1. Edit copy in `src/content.mjs` and your details in `site.config.json`:
   - `email`, `phone`, `phoneDisplay`, `whatsapp` (digits only, with country code) — **the phone/WhatsApp numbers in the file are placeholders**.
   - `social` links (empty ones are hidden).
   - `leadIntakeUrl` — see below.
   - `proof`, `testimonials`, `caseStudies` — real numbers only; empty values stay hidden.
   - `receipts.lighthouse` — the score shown on the home page. Re-run Lighthouse after big changes; clear it to hide that block.
2. Build: `node build.mjs` (Node 18+). Output goes to `dist/`. If `esbuild` is installed globally the script is minified; otherwise it ships as-is.
3. Publish it — see **Go live** below.

Preview build for a sub-folder or static preview host: `PREVIEW=1 node build.mjs` (relative links, forms show a success message without sending).

## Go live

Two ways. Pick one.

### A. On the VPS, next to internal.dotindot.in (recommended)

Forms reach the CRM without editing files, and every later update is one command.

1. **DNS** (hPanel → Domains → dotindot.in → DNS / Nameservers): point the `@` A record **and** `www` at the VPS IP (the same IP `internal` uses). Delete any other A/AAAA/CNAME records for `@` and `www` that point to the old site builder. Leave MX, TXT and other email records alone.
2. **Code**: after v3.2 is merged, run the usual `/var/www/dotindot/deploy.sh` so `website/` is on the server.
3. **CRM capture link** (kept out of git):
   `echo "INTAKE_URL=https://internal.dotindot.in/api/intake/leads/$(read -rsp 'Paste intake key: ' k; echo $k)" | sudo tee /var/www/dotindot/website.env >/dev/null`
   The key is the end of **Lead Flow → Our capture link** in internal.dotindot.in.
4. **Build and publish**: `bash /var/www/dotindot/website/deploy-website.sh` → builds into `/var/www/dotindot.in` (keeps the previous build in `/var/www/dotindot.in.prev`).
5. **nginx + HTTPS** (once):
   ```
   sudo cp /var/www/dotindot/website/deploy/nginx-dotindot.in.conf /etc/nginx/sites-available/dotindot.in
   sudo ln -sf /etc/nginx/sites-available/dotindot.in /etc/nginx/sites-enabled/dotindot.in
   sudo nginx -t && sudo systemctl reload nginx
   sudo certbot --nginx -d dotindot.in -d www.dotindot.in --redirect
   ```
   Run certbot only after DNS from step 1 has switched (`dig +short dotindot.in` shows the VPS IP).
6. **Let the website post leads**: in the backend `.env` set `CORS_ORIGINS=https://dotindot.in,https://www.dotindot.in,https://internal.dotindot.in`, then `pm2 restart dotindot-backend`.

Later updates: `/var/www/dotindot/deploy.sh && bash /var/www/dotindot/website/deploy-website.sh`.

### B. On Hostinger web hosting (no server work)

1. hPanel → Websites: if dotindot.in is a Website Builder / Horizons site, disconnect the domain from it, then add dotindot.in to your web hosting plan.
2. Put the intake key in `site.config.json` → `leadIntakeUrl`, run `node build.mjs`.
3. hPanel → File Manager → `public_html`: delete the old files, upload the **contents** of `dist/` (or the upload zip, then Extract). Keep `.htaccess` and `.well-known`.
4. hPanel → Security → SSL: install the free certificate and turn on Force HTTPS.
5. Same CORS step as A6 on the VPS.

Every later change: rebuild and upload again.

### After either

- Open https://dotindot.in, https://www.dotindot.in (should land on dotindot.in) and an old link such as /work (should land on /process/).
- Send one test lead from the Free audit page and check it appears in Lead Flow.
- Replace the placeholder phone/WhatsApp in `site.config.json`, rebuild, publish.
- Search Console + Bing: verify, then submit `https://dotindot.in/sitemap.xml` (see below).

## Search engines (once)

- Search Console / Bing: paste the HTML-tag verification values into `verify.google` / `verify.bing`, rebuild, upload, then submit `https://dotindot.in/sitemap.xml` in both.
- Optional: put a free Google Cloud API key (PageSpeed Insights API enabled) in `pageSpeedApiKey` so the speed test gets a bigger daily quota.
- Share images: `node og.mjs` (needs Playwright) re-renders `assets/og/*.jpg` after you change titles; then rebuild.
- Every page ships with title, description, canonical, hreflang, Open Graph/Twitter cards with its own image, and JSON-LD (Organization, WebSite, WebPage with speakable, BreadcrumbList, Service, FAQPage, ItemList, Blog/BlogPosting, HowTo, WebApplication for the free tools). Also `sitemap.xml`, `robots.txt` (AI crawlers welcome), `llms.txt`, `llms-full.txt`, `humans.txt` and `.well-known/security.txt`.

## Connect the forms to the CRM (once)

1. In internal.dotindot.in open **Lead Flow → Our capture link** and copy the key at the end of the link.
2. Put it in `site.config.json` → `leadIntakeUrl`: `https://internal.dotindot.in/api/intake/leads/<your key>` and rebuild.
3. On the VPS, make sure the backend `.env` allows the website: `CORS_ORIGINS=https://dotindot.in,https://www.dotindot.in,https://internal.dotindot.in`, then `pm2 restart dotindot-backend`.

## Files

- `build.mjs` — page templates, schema, sitemap, robots, llms.txt, .htaccess
- `src/content.mjs` — all copy (services, process, FAQs, jokes, articles, roles, markets, quiz)
- `src/scenes.mjs` — the six animated service films (SVG)
- `og.mjs` — renders the per-page share images (dev only)
- `deploy-website.sh` — builds and publishes to `/var/www/dotindot.in` on the VPS
- `deploy/nginx-dotindot.in.conf` — the nginx site for dotindot.in
- `src/styles.css` — design tokens and styles (inlined into every page)
- `src/site.js` — Dot (moods, throwing, logo landing), smooth scroll, scenes, quiz, speed test, clocks, currency, forms
- `assets/fonts` — Anybody + Instrument Sans, subset to Latin (both SIL Open Font License)
- `assets/vendor` — Lenis (MIT) and the dotted world-map points
